# 1. Purpose

Dokumen ini mendefinisikan ruang lingkup pengembangan Grand Titik Kumpul CMS pada versi pertama (V1).

Tujuan utama dokumen ini adalah menjaga fokus pengembangan agar sistem dapat selesai lebih cepat, mudah dipelihara, dan sesuai dengan kebutuhan bisnis saat ini.

---

# 2. Scope Overview

Grand Titik Kumpul CMS V1 difokuskan sebagai:

> **Marketing Website & Booking Management System**

Sistem berfungsi sebagai media promosi digital sekaligus platform booking online yang terintegrasi dengan CMS untuk mengelola produk, booking, pembayaran, dan dashboard bisnis.

---

# 3. In Scope (V1)

## Marketing Website

Website berfungsi sebagai media promosi digital yang menampilkan seluruh produk dan informasi perusahaan.

Fitur meliputi:

- Landing Page
- Hero Banner
- Product Catalog
- Product Detail
- Bundle Promotion
- Gallery
- FAQ
- Testimonial
- Google Maps
- Contact Information
- Floating WhatsApp
- Dark Mode
- Responsive Mobile Design

---

## Booking System

Customer dapat melakukan booking secara mandiri melalui website.

Fitur meliputi:

- Pilih Paket
- Pilih Tanggal
- Pilih Slot
- Input Jumlah Peserta
- Input Data PIC
- Catatan Tambahan
- Generate Booking
- Generate Invoice

---

## Payment

Pembayaran dilakukan melalui transfer bank dengan verifikasi manual.

Fitur meliputi:

- DP Minimal 50%
- Pelunasan Maksimal H-1
- Upload Bukti Transfer
- Upload Ulang Sebelum Status Lunas
- Verifikasi Manual oleh Admin/Marketing Manager

---

## Product Management

Marketing Manager dapat mengelola seluruh produk.

Fitur meliputi:

- Tambah Paket
- Edit Paket
- Hapus Paket
- Aktif / Nonaktif Paket
- Kelola Harga
- Kelola Minimal Peserta
- Kelola Slot
- Kelola Bundle
- Kelola Add-on

---

## Promotion Management

Marketing Manager dapat mengelola promosi.

Fitur meliputi:

- Promo
- Diskon Persentase
- Custom Discount
- Promo Aktif / Nonaktif

---

## Dashboard

Dashboard digunakan untuk monitoring aktivitas bisnis.

Menampilkan informasi:

- Total Booking
- Total Customer
- Pending Payment
- DP
- Pelunasan
- Booking Hari Ini
- Booking Bulan Ini
- Paket Terlaris
- Grafik Booking

# 5. Business Goals

Implementasi V1 bertujuan untuk:

- Meningkatkan jumlah booking melalui website.
- Mengurangi proses booking manual.
- Menyimpan seluruh data booking dalam database.
- Mempermudah pengelolaan produk.
- Mempermudah monitoring penjualan.
- Menyediakan dashboard bagi Owner dan Marketing Manager.

---

# 6. Success Criteria

Project V1 dinyatakan berhasil apabila:

- Customer dapat melakukan booking secara mandiri.
- Customer dapat memilih tanggal dan slot kegiatan.
- Customer dapat mengunggah bukti pembayaran.
- Marketing Manager dapat mengelola produk tanpa bantuan developer.
- Dashboard menampilkan data bisnis secara real-time.
- Seluruh data tersimpan dengan baik di database.

# 8. Scope Boundary

Seluruh pengembangan Grand Titik Kumpul CMS V1 difokuskan pada proses:

Marketing → Booking → Payment Verification → Dashboard

Aktivitas setelah customer dinyatakan siap mengikuti kegiatan (operasional lapangan) berada di luar ruang lingkup V1.
